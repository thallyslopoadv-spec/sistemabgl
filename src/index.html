Novo prazo

Publicações do DJEN

O sistema consulta o Diário de Justiça Eletrônico Nacional pelas OABs abaixo, liga cada publicação ao processo pelo número CNJ (ou cadastra o processo) e calcula o prazo: pelo texto da publicação, pela lei do ato publicado ou, na falta de ambos, pelo prazo geral de 5 dias úteis. O prazo vai para a Rotina marcado a conferir. Informe em "Advogado(a)" o nome do sócio para que os prazos daquela OAB caiam com ele.

Tipos de tarefausados na Rotina e nas pendências
Sua senha
A senha vale para todos os dispositivos e é ela que destranca o token guardado neste computador. Use pelo menos 8 caracteres e não repita senha de outro serviço.

Backup dos dados

Atenção: restaurar substitui os dados atuais do sistema pelos dados do arquivo. Antes de gravar, o sistema baixa automaticamente um backup do estado atual, para nada ser perdido caso você restaure o arquivo errado.
Cópias automáticas neste navegadorguardadas a cada alteração
O sistema guarda sozinho as últimas versões dos dados neste computador. Servem para desfazer um erro recente — não substituem o backup baixado, porque somem se o navegador for limpo.
Cópia automática no repositório
Quando ligado, o sistema envia uma cópia de todos os dados para o repositório a cada alteração. Só ligue se esse repositório for privado — num repositório público, os dados dos clientes ficam visíveis para qualquer pessoa da internet.

Lembrete de backup
O sino de alerta no botão de backup aparece quando passam mais de 7 dias sem uma cópia baixada. Baixe o "Sistema completo" pelo menos uma vez por semana e guarde em dois lugares diferentes (computador + nuvem pessoal ou pendrive).
